# Space Kat — Concept Website

A presentation-ready artist website concept for **Space Kat**, Kingston, Jamaica.

## Concept
A dark, editorial Jamaican-futurist visual system built around music, live performance, EPK and booking. This prototype intentionally uses abstract image placeholders until approved artist photography and official release artwork are supplied.

## Run
Open `index.html` locally or deploy the repository as a static site.
